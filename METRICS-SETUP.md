# Profile metrics

The profile README is rendered from the public `7byteDev/7byteDev` repository. `github-metrics.svg` is generated by a stable, commit-pinned lowlighter/metrics GitHub Action.

- Schedule: every day at 03:17 UTC (06:17 Europe/Istanbul).
- Manual refresh: Actions > GitHub Metrics > Run workflow.
- Inputs: public account overview, public repository languages and half-year contribution calendar.
- `METRICS_TOKEN`: a dedicated classic personal access token without additional scopes, stored only in Actions secrets. Do not commit it.
- `GITHUB_TOKEN`: generated per workflow run, restricted to this repository; used to commit the generated SVG.

To rotate the metrics token, create a new scopeless token and replace the repository Actions secret named METRICS_TOKEN. If a token expires, update this secret and rerun the workflow.

Upstream setup: https://github.com/lowlighter/metrics/blob/master/.github/readme/partials/documentation/setup/action.md
